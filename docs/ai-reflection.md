# Reflexión sobre IA

## Herramientas usadas
ChatGPT para diseño y generación de código base.

## Uso realizado
- Generación de clases iniciales
- Ayuda en UML
- Corrección de errores de Java
- Generación de documentación

## Problemas detectados
- Errores en métodos de Java (ej: Set.allOf inexistente)
- Implementaciones que requirieron ajuste manual

## Validación
Todo el código fue revisado manualmente y probado con ejecución en Main.

## Conclusión
La IA acelera el desarrollo, pero no sustituye el análisis del programador.
