# Smart Alarm System

## Descripción del proyecto
Sistema de lógica de un despertador inteligente desarrollado en Java sin interfaz gráfica. Simula funcionalidades avanzadas de alarmas modernas como repetición, snooze, modos inteligentes y estadísticas de sueño.

## Objetivos
- Diseñar software orientado a objetos
- Aplicar principios SOLID básicos
- Gestionar proyecto con Git y GitHub
- Documentar mediante UML y Markdown
- Utilizar IA como herramienta de desarrollo

## Tecnologías utilizadas
- Java
- Git / GitHub
- Mermaid (UML)
- Markdown

## Instalación y ejecución
1. Clonar repositorio
2. Abrir en IntelliJ / Eclipse
3. Ejecutar Main.java

## Estructura del proyecto
/src → código fuente
/docs → documentación UML y casos de uso
/tests → pruebas

## Funcionalidades
- Gestión de alarmas
- Repetición semanal
- Snooze
- Modo vacaciones
- Alarmas inteligentes
- Despertar circadiano
- Estadísticas de sueño

## Diseño orientado a objetos
El sistema está dividido en:
- Modelos (Alarm, AlarmManager, etc.)
- Servicios (Snooze, Scheduler, etc.)

## UML
Incluye diagramas de clases y casos de uso en Mermaid.

## Uso de IA
Se ha utilizado IA para:
- generación de estructura base
- diseño de clases
- documentación inicial
- revisión de errores

## Reflexión
La IA acelera el desarrollo, pero requiere validación humana para evitar errores lógicos.
