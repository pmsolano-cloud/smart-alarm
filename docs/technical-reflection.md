# Reflexión técnica

## Decisiones de diseño
Se ha utilizado arquitectura orientada a objetos separando modelos y servicios.

## Problemas encontrados
- Gestión de duplicados en alarmas
- Modelado de repetición semanal
- Control de responsabilidades entre clases

## Mejoras futuras
- Persistencia en base de datos
- Interfaz gráfica
- Sincronización en la nube

## Deuda técnica
- Falta de tests unitarios completos
- Falta de persistencia

## Patrones aplicados
- Separación de responsabilidades
- Encapsulación
