# Smart Alarm System

## Descripción
Sistema de alarmas inteligente en Java sin interfaz gráfica. Permite crear, gestionar y controlar alarmas con funcionalidades avanzadas como snooze, modo vacaciones y repetición semanal.

## Funcionalidades principales
- Crear y eliminar alarmas
- Activar/desactivar alarmas
- Repetición semanal configurable
- Snooze (posponer alarma)
- Modo vacaciones
- Despertar circadiano
- Estadísticas de sueño
- Detección de conflictos entre alarmas
